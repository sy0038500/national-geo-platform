# 📄 제품 요구사항 정의서 (PRD)

## 국토정보플랫폼 UI/UX 개선 – 인터랙션 피드백 중심 리디자인

---

## 1️⃣ 프로젝트 배경

국토정보플랫폼은 다양한 지도 데이터를 제공하는 공공기관 웹사이트로, 일반 사용자부터 전문가까지 폭넓은 이용자를 대상으로 한다.

그러나 현재 서비스는 클릭 가능한 요소에 대한 시각적 피드백 부재와 인터페이스의 직관성 부족으로 인해, 사용자가 제공된 기능을 인지하고 활용하는 데 어려움을 겪고 있다.

또한, 지도 서비스가 전문 용어 중심으로 구성되어 있어 일반 사용자가 각 지도 서비스의 의미와 용도를 직관적으로 이해하기 어려운 문제가 존재한다.

이에 따라 본 프로젝트는 상호작용 피드백 개선을 중심으로 사용자 경험을 향상시키고, 단계적으로 정보 구조와 이해도를 개선하여 사용자의 탐색 흐름을 자연스럽게 연결하는 것을 목표로 한다.

---

## 2️⃣ 문제 정의

현재 국토정보플랫폼은 다음과 같은 세 가지 핵심 UX 문제를 가지고 있다.

### ① 행동(Interaction) 문제

- 클릭 가능한 요소(‘더보기’ 등)가 시각적으로 구분되지 않음
- hover 및 focus 상태가 없어 상호작용 여부를 인지하기 어려움
- 사용자가 행동을 시도하기 전에 주저하게 되는 구조

→ 결과: 행동 단계에서 UX 흐름 단절

---

### ② 구조(Visual Structure) 문제

- 콘텐츠 간 시각적 구분이 부족함
- 정보 간 위계와 그룹이 명확하지 않음
- 모든 요소가 유사한 형태로 나열되어 있음

→ 결과: 사용자가 어디를 봐야 하는지 판단하기 어려움

---

### ③ 인지(Cognitive) 문제

- ‘수치지도’, ‘정사영상’ 등 전문 용어 중심 구성
- 지도 기능 및 용도를 직관적으로 이해하기 어려움
- 클릭 이전 단계에서 인지적 부담 발생

→ 결과: 서비스 이해 실패 및 탐색 피로 증가

---

## 3️⃣ 핵심 UX 가설

만약 우리가 클릭 가능한 모든 요소(버튼, 링크)에 hover 및 focus 시 시각적 피드백(색상 변화, 테두리 등)을 제공하면,  
사용자들은 어떤 요소가 상호작용 가능한지 즉시 인지하여 더 빠르고 정확하게 탐색할 수 있을 것이다.  
왜냐하면 시스템 상태의 가시성이 확보되면 사용자는 별도의 추측 없이 행동을 결정할 수 있기 때문이다.

※ 본 가설은 1차 개선 단계(행동 문제 해결)에 해당하며, 이후 구조 및 인지 문제를 단계적으로 개선한다.

---

## 4️⃣ 타겟 페르소나

### 👤 김영수 (62세)

- 직업: 은퇴 후 귀농 준비 중 (전직 자영업자)
- IT 숙련도: 낮음 (모바일 중심, 웹 사용 경험 제한적)
- 이용 목적: 농지 위치 확인을 위한 지도 정보 조회

### 💥 Pain Point

- 클릭 가능한 요소인지 구분이 어려움
- 인터페이스에 대한 확신 부족
- 정보 구조가 복잡하여 탐색이 어려움
- 지도 용어를 이해하기 어려움
- 반복 시도 후 피로 누적 및 이탈 가능성 증가

---

## 5️⃣ 핵심 요구사항 및 기능 명세

### 🎯 목표

사용자가 클릭 가능 요소를 즉시 인지하고 행동으로 이어지도록 하며,  
정보 구조를 명확히 하고, 지도 서비스에 대한 이해를 돕는다.

---

### 🔧 기능 요구사항

#### ① Hover 인터랙션 피드백 (1차 개선)

- 모든 클릭 가능한 요소에 hover 상태 적용
- 적용 대상: 버튼, 링크, ‘더보기’ 텍스트
- 구현 방식:
  - 배경색 변화
  - 텍스트 색상 변화
  - (선택) 미세 애니메이션

---

#### ② Focus 상태 시각화 (접근성 포함)

- 키보드 포커스 시 outline 또는 테두리 표시
- WCAG 기준을 만족하는 명확한 대비 적용

---

#### ③ 클릭 가능 요소 시각적 구분

- cursor: pointer 적용
- 버튼 형태 강조 (배경, radius 등)

---

#### ④ 콘텐츠 블록 간 시각적 구분 강화 (2차 개선)

- 카드형 UI를 활용한 정보 그룹화
- 콘텐츠 간 간격 및 여백 확보
- 테두리 또는 배경 대비를 통한 시각적 분리
- 시각적 계층 구조 설계 (크기, 정렬, 강조 요소)

---

#### ⑤ 지도 용어 설명 기능 (Information Icon) (3차 개선)

- 각 지도 이름 옆에 해당 지도에 대한 설명 표시

- 제공 정보:
  - 지도 설명 (한 줄 요약)
  - 지도 사용 목적
  - (선택) 예시 이미지

- UX 원칙:
  - 사용자가 별도의 클릭 없이 즉시 이해할 수 있도록 설계
  - 전문 용어를 직관적인 설명으로 보완

- 접근성 고려:
  - 스크린리더를 위한 대체 텍스트 제공
  - 텍스트는 충분한 대비와 가독성을 확보

---

### 🧭 To-Be Task Flow

접속 → 탐색 → hover 인지 → 클릭 → 상세 진입 → 목표 달성

---

## 6️⃣ 성공 측정 지표 (Success Metrics)

### 📊 정량 지표

- 클릭률(CTR) 증가 (예: ‘더보기’ 클릭 비율)
- 평균 탐색 시간 감소
- 이탈률 감소 (지도 목록 페이지 기준)

---

### 📊 정성 지표

- 사용자 테스트 시:
  - “클릭 가능한지 헷갈린다” 발언 감소
  - “어디를 봐야 할지 모르겠다” 발언 감소
  - “지도 의미를 이해하기 어렵다” 발언 감소

---

### 🎯 핵심 KPI

클릭 가능 요소 인지율 향상 → 행동 전환율 증가

---

## 🔥 최종 요약

본 개선은 단순한 UI 변경이 아니라,  
사용자의 행동(Interaction) → 구조(Structure) → 이해(Cognition) 흐름을 단계적으로 개선하는 UX 전략이다.

이를 통해 사용자가 기존 기능을 인지하고 사용할 수 있도록 하며,  
초보 사용자도 쉽게 서비스를 이해하고 활용할 수 있는 환경을 구축한다.
